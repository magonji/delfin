What it is

A complete personal finance system

Delfin is a FastAPI backend and a vanilla-JavaScript front end. It imports your Financisto database, keeps every figure in the currency it happened in while converting for display at the rate of that day, and stores the lot in a SQLite file encrypted with SQLCipher. One Docker command and it is up; the only request it makes to the outside world is to the European Central Bank, for exchange rates.

Multi-currency

Every rate, on its own date

Hold accounts in any currency the ECB publishes. Conversions use the rate from the day of the transaction, not today's.

Encrypted at rest

Locked until you log in

SQLCipher with AES-256. The key lives only in memory, so a restart leaves the app locked — and the backups are encrypted too.

Runs anywhere

arm64 and amd64

One multi-arch image, so Docker pulls the right one for your host. Housekeeping happens in a single nightly pass.

Features

Dashboard

The whole picture

  • Net worth evolution — daily, weekly or monthly, over any range, with accounts excludable one by one
  • Spend by category — doughnut with month navigation, by top expense, category or subcategory
  • Trends — income against expenses by month and by year, plus category trends over time
  • Top payees and monthly transaction volume
Transactions

Built for fast entry

  • Save & New batch mode — balance recalculation deferred until the last save
  • Payee autocomplete that remembers the usual category and location
  • Transfers across currencies, with the rate shown
  • Bulk edit, advanced filters and infinite scroll
  • Running balances per account and portfolio-wide on every row
Budget

Kakeibo, month by month

  • Four buckets — essentials, indulgences, culture, unexpected — mapped from your own categories
  • A month calendar marking what falls on each day, and what has already been paid
  • Fixed costs, expected income and planned expenses as definitions that materialise into each month
  • Anything longer than a month is prorated — a bill every six months becomes a monthly sinking fund
  • Closed months keep their record: an edit applies from the month you are looking at onwards
Loans & cards

Debt, worked out for you

  • Tells cards from loans automatically, by the shape of the spending
  • Borrowed, repaid, interest, outstanding — and an estimated APR via XIRR
  • Lender detected from the payees on the account
  • Card progress bars against your historical maximum debt
Tools

Your data stays portable

  • Financisto in and out — native .backup or CSV, with a compatibility report before anything is written
  • Any bank CSV via a column-mapping step, with reusable per-bank profiles and duplicate detection
  • Merge duplicates across categories, accounts, payees, locations and projects
  • Backup and restore using SQLite's online backup API — consistent, never a raw file copy
Throughout

The quiet parts

  • Multi-currency — every currency in the ECB feed, converted at the rate of the transaction date
  • Nightly maintenance — rates, balances, payee stats and an off-disk backup, but only when your data actually changed
  • PWA — installable on iOS, Android and desktop, with a service worker
  • No frameworks — vanilla JavaScript and Chart.js, so there is nothing to keep upgrading
Getting started

Up in one command

The image is published to the GitHub Container Registry and rebuilt for arm64 and amd64 on every push. Docker pulls the right one for your host. 

# Clone and start — the database persists in ./data
$ git clone https://github.com/magonji/delfin.git
$ cd delfin
$ docker compose up -d
# Or run the published image directly
$ docker run -d --name delfin --restart unless-stopped \
    -e TZ=Europe/Madrid \
    -p 8422:8422 \
    -v "$(pwd)/data:/app/data" \
    ghcr.io/magonji/delfin:latest
1

Open it

Go to http://<host>:8422/app/index.html and set a password. Save the recovery code it shows you — there is no other way in.

2

Bring your data

Tools → Import Financisto, or map any bank CSV. You get a compatibility report first, so nothing is dropped without telling you.

3

Install it

Add it to your home screen. It is a PWA, so it behaves like an app on the phone and keeps working while the page reloads in the background.

Prefer to run it from source? Python 3.9+, pip install -r requirements.txt, then uvicorn backend.main:app --port 8422. Full instructions in the README.

Security

Encrypted, and locked until you say so

A random 256-bit key encrypts the database. That key is stored wrapped twice — once behind your password, once behind your recovery code — so changing the password only re-wraps it. The database is never re-encrypted, and existing backups stay valid.

Over plain HTTP on a LAN the password and cookie travel unencrypted. For real protection put Delfin behind HTTPS — a reverse proxy or Tailscale. And keep your password, recovery code and keyfile safe: losing them means the data is unrecoverable, by design.
